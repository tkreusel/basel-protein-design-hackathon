## Pipeline (what each column means)
1. RFD4-Proteina generation (hgnt = HG3.17 Gln50+Asp127+6NT, hgwt = + Trp44). Arms: unsteered | steer_tmol (base polar/cation/SASA/apolar, pocket ratio, nitro, motif rigidity, clashes + TMol dG) | steer_tmol_ch18 (+ bottleneck radius band 1.7-1.9 A). `_sheet` = beta-sheet-conditioned diversity add-on (small n). 300 designs per run (steered: 100 lineages x 3 beam members, members are near-identical backbones, CA RMSD 0.03 A).
2. Design gate (design_metrics.csv / all_designs_metrics.csv): pass_geom (ligand SASA<=0.10, base SASA<=0.10, pocket ratio 0.4-1.4, no clashes, motif RMSD<=0.3 A), pass_seq (no side-chain polar atoms <=4.5 A of base, no Lys/Arg <=6 A, nitro H-bond far from base, TMol dG<0), pass_core = both. Steered arms need pass_core, unsteered need pass_geom; if <30 pass, best remaining fill up (gate_tier 2/3).
3. LigandMPNN: RFD4-native + 4 full redesigns (T 0.1, KRHDENQSTYC forbidden within 6 A of base carboxylate) + (steered only) 1 shell-fixed (motif + residues <=5 A of ligand or <=6 A of base kept).
4. Boltz-2 1x TSA (6NT, no MSA) + gate: pLDDT>=80, CA RMSD<=2 A, ligand ipTM>=0.6, ligand RMSD<=2 A, motif-tip RMSD<=1 A, refold geometry (pocket/base/nitro). boltz_tier 1 = strict pass, 2 = fallback (>=10 sequences per run).
5. Survivors: Boltz-2 x9 more TSA, x10 substrate (H5J), x10 product (6VP). Best sample per ligand = lowest pocket RMSD to the design. Report columns: 6NT./H5J./6VP.<scrmsd|pocket_rmsd|iptm|ligand_iptm|complex_ipde|complex_plddt>.mean/.sd, delta_*.TSA_minus_sub / TSA_minus_prod.
6. Full eval on best sample(s): ipSAE2 (ipsae.tsa/sub/prod, all samples), PLACER 20 models for holo TSA/substrate/product + apo (placer.holo.frac_pass_core, placer.apo.frac_pass_core = fraction of ensemble in the crystal-derived catalytic geometry), tmol protocol (delta.tsa_minus_sub.total, strain, constraint deviations), PyRosetta (ros.tsa.dG_sep, ros.delta_native.tsa_minus_sub.dG_sep, Sc unreliable).
7. Extended evaluation (eval_set = extended): next-best <=20 non-survivor sequences per finished run (relaxed Boltz-1x criteria, max 3 per design) through step 5-6.

## Caveats
Panel rank is uncalibrated and report only (no activity labels). TMol is a steering reward: use PyRosetta/PLACER for arm comparisons. Unsteered is gated geometry-only, steered full core. PLACER reference windows come from HG3-lineage crystals. Boltz ipTM is saturated (0.85-0.94). 6NT is a neutral TSA, 6VP is the neutral phenol.
