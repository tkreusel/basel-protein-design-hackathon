## 1. Goal
Scaffold a Kemp-eliminase active site (catalytic carboxylate base + oxyanion partner + TS-analogue ligand 6NT) into a 150-260 aa
protein with **RFD4-Proteina** (NVIDIA, `nvidia/RFD4-Proteina`, rev a06e2509) and **steer** generation toward a catalytically
sensible pocket using custom reward metrics, then do sequence design + refolding.
Motifs (all unindexed, tip atoms fixed + sequence fixed, ligand fixed):
- `hg317-tips_with-trp`: HG3.17 Trp44 ring + Gln50 side chain + Asp127 carboxylate + 6NT
- `hg317-tips_no-trp`: same without Trp44 (Gln50 + Asp127)
- `gdm1483-glu-ser`: theozyme GDM_KE_1483 (Glu base + Ser partner + 6NT)

## 2. What "steering" means here (RFD4, not RFD3)
RFD4 has a built-in **beam search** (`search:` block, `rfd4/src/rfproteina/search/beam_search.py`): n_branch branches are
denoised K steps from each beam member, scored by a weighted sum of metrics ("rewards"), top `beam_width` kept.
Our config: 4 branches x beam 3, checkpoints at denoising steps 30/42/52 (score the *predicted clean structure*, no rollout) and 60 (final).
Each replicate returns 3 beam members (= 3 designs per replicate, same lineage; count lineages, not designs, when judging diversity).
Rewards are written per checkpoint in `rfd4_patch/configs/inference_experiment/r4_*.yaml` (generated by `code/make_r4.py`, `make_r5.py`).
Steering is **non-differentiable, resampling only**. Conditioning (burial `C_RAS`, hydrophobic `C_HPHOB`, nitro-O `C_HB` acceptor, fixed tips) is in the
input specs (`inputs/kemp4_*.yaml`) and applies to ALL arms including unsteered.

Custom metrics (`rfd4_patch/custom_metrics/`, drop into `rfd4/src/rfproteina/metrics/custom_metrics/`; configs reference `kemp_base`, `kemp_pocket3`, `kemp_chem`, `kemp_chem_hg`, `kemp_channel`, `tmol_lig_ddg`):
- `kemp_base.py`: catalytic base burial (rel. SASA), apolar environment fraction, side-chain polar atoms within 4.5 A of base O, Lys/Arg within 6 A, nitro H-bond donors (far/near base), ligand and protein clashes.
- `kemp_pocket.py`: grid pocket volume / ligand volume (3 A clearance + ray enclosure; NOT fpocket), ligand SASA fraction, loop fraction in 8 A shell.
- `kemp_chem.py`: locates the unindexed motif residues by superposing the reference theozyme on the ligand; base/partner RMSD (motif rigidity).
- `kemp_channel.py`: probe-radius connectivity from ligand pocket to bulk (ligand removed): `bottleneck_radius`; reward = band 1.4-1.9 A (water passes).
- `kemp_tmol.py`: TMol protein-ligand interface dG (wrapper strips RFD4 conditioning annotations; needs prebuilt `inputs/6NT.tmol`).
`rfd4_patch/pyproject.diff`: bionemo-ir removed from extras (needs GLIBC 2.34, Helix has 2.28).

## 3. Arms (per motif)
`unsteered` (conditioning only) | `steer_base` (all geometry rewards) | `steer_base_tmol` (+ TMol dG, weight 0.5/20) | `steer_base_channel` (+ solvent-channel band reward, ligand SASA penalty relaxed). Rounds r0-r3 were earlier iterations (RFD3 FK, pocket-only, crystal calibration; see `code/SUMMARY_20261121_trials.md`, `early_rounds_metrics/`); r4 = hard base polar exclusion + motif rigidity + nitro conditioning; r5 = channel arm + more seeds + downstream.
Seeds: 7 (r4), 11, 12 (r5; s13 cancelled). N_REP=3 replicates per steered arm, 6 for unsteered.

## 4. Pipeline / how to run
1. `make_r4.py`, `make_r5.py` -> experiment YAMLs. 2. `sbatch run_r5_job.sbatch <campaign> <seed> <arm>...` -> `run_r5.py` (generate -> flatten to `structures/<arm>/s<seed>/designs/*.cif` -> per-design metrics CSV in `metrics/`). 3. `eval_r5.py` aggregates to `runs/20261121_r5_SUMMARY/` (core criteria below). 4. `downstream/`: `select_passers.py` (passers -> `designs_in/`), `prep_mpnn.py` (LigandMPNN T=0.1, 4 seq/design, motif fixed, KRHDENQSTYC omitted within 6 A of base carboxylate), `prep_boltz.py` -> `run_boltz_chunk.sbatch` (Boltz-2, no MSA, protein + CCD 6NT), `eval_boltz.py`/`.sbatch` (confidence, CA/ligand/motif RMSD to design, same chemistry metrics on the predicted complex, TMol).
Core pass criteria (`eval_r5.py`): ligand SASA<=0.10, base rel SASA<=0.10, base side-chain polar atoms<=0 (<=1 for with-Trp: fixed Trp44 NE1), no Lys/Arg<=6 A, volume ratio 0.4-1.4, nitro H-bond far>=1 and none near base, no clashes, motif RMSD<=0.3 A (base and partner), TMol dG<0. `channel_ok` = bottleneck>=1.4 A.

## 7. Caveats (state these when reporting)
- **Circularity**: pass criteria == reward terms; passing is not evidence of catalytic competence. TMol dG is the only partly independent term, and it is also a reward in one arm.
- Small n (2-3 seeds x 3 replicates); lineage counts, not design counts, are the effective sample size. No CIs computed.
- Pocket volume is a grid proxy; channel bottleneck uses a 0.5 A grid; pocket/channel are heavy-atom geometric screens (no hydrogens).
- Boltz-2 refolds / MPNN sequences: pipeline built and a 2-sequence test ran (54 s); NO Boltz-2 results yet, so designability (does the sequence refold to the design with the motif/ligand intact) is untested.
- Pending/unverified: `eval_boltz.py` has not been run on real chunks; `channel_arm_vs_others.csv` mentioned in `eval_r5.py` docstring is not produced.
